# QuickStock SDK 知识库

## 项目概述

QuickStock SDK 是一个易于使用的金融数据获取工具包，用于获取股票、指数、基金和板块数据。该项目的目标是提供一个既简单又可维护的SDK，解决之前两个版本（`quick_stock` 太简单，`release_config` 太复杂）的问题。

## 目录结构

项目采用了 Python 包的最佳实践 **src-layout** 结构：

```
quickstock/
├── docs/           # 文档目录

├── tests/          # 测试目录
```

## 核心功能

### 数据类型支持
- **股票数据**：基础信息、日线、分钟线、周线、月线
- **指数数据**：基础信息、日线、分钟线、周线、月线
- **基金数据**：基础信息、日线
- **板块数据**：概念板块列表、板块成分股、板块K线数据（日线、周线、月线、分钟线）

### API 设计
- **同步接口**：如 `stock_basic()`、`stock_daily()`、`concept_list()`
- **异步接口**：如 `astock_basic()`、`astock_daily()`、`aconcept_list()`
- **统一返回格式**：所有方法都返回 pandas DataFrame

### 数据源
- **Baostock数据源**：用于获取股票、指数、基金数据
- **同花顺数据源**：用于获取板块数据（概念板块、板块成分股、板块K线）
- **数据源接口**：通过抽象基类定义统一的数据源接口

### 同花顺数据源详解

#### 功能特性
- **概念板块列表**：获取所有概念板块的基本信息（代码、名称、cid）
- **板块成分股**：获取指定概念板块的成分股列表
- **行业板块列表**：获取所有行业板块的基本信息（代码、名称）
- **行业成分股**：获取指定行业的成分股列表
- **板块K线数据**：支持日线、周线、月线、1分钟线、30分钟线、60分钟线

#### 数据结构
概念板块数据包含三个关键字段：
- `code`：板块代码（如 885333），用于获取K线数据
- `name`：板块名称（如 移动支付）
- `cid`：板块ID（如 300188），用于获取成分股

行业成分股数据包含以下字段：
- `code`：股票代码
- `name`：股票名称
- `industry_code`：行业代码

#### API端点
- 概念板块列表：`http://q.10jqka.com.cn/gn/`
- 板块成分股：`http://q.10jqka.com.cn/gn/detail/field/199112/order/desc/size/1000/page/1/ajax/1/code/{cid}`
- 行业板块列表：使用akshare接口`ak.stock_board_industry_name_ths()`
- 行业成分股：`http://q.10jqka.com.cn/thshy/detail/field/199112/order/desc/page/{page}/ajax/1/code/{industry_code}`
- 板块K线数据：`https://d.10jqka.com.cn/v4/line/bk_{code}/{klt}/{year}.js`
  - klt参数：01=日线, 11=周线, 21=月线, 61=1分钟, 41=30分钟, 101=60分钟

#### 重要注意事项
1. **获取概念成分股必须使用cid**，不能使用code
2. **获取K线数据必须使用code**，需要添加`bk_`前缀
3. **获取行业成分股使用行业代码**，如"881101"（医药行业）
4. 数据缓存机制：已获取的数据会缓存在内存中，避免重复请求
5. 分钟线数据：1分钟线数据量较大，建议谨慎使用

#### 数据字段说明
K线数据包含以下字段：
- `date_at`：日期/时间
- `start`：开盘价
- `end`：收盘价
- `max`：最高价
- `min`：最低价
- `count`：成交量
- `amount`：成交额
- `amplitude`：振幅
- `range`：涨跌幅
- `range_amount`：涨跌额
- `turnover_rate`：换手率

## 技术架构

### 1. 核心模块

#### client.py
- 提供 `QuickStockClient` 类，是用户与SDK交互的主要接口
- 实现了同步和异步两种调用方式
- 内部使用 `_run_async()` 方法将异步方法包装为同步接口

#### errors.py
- 定义了统一的异常处理体系
- 基础异常：`QuickStockError`
- 子类异常：`DataSourceError`、`ValidationError`、`AuthenticationError`、`NetworkError`、`DataNotFoundError`

#### sources/
- **base.py**：定义数据源抽象基类，规定了必须实现的接口方法
- **baostock.py**：Baostock 数据源的具体实现，用于获取股票、指数、基金数据
- **tonghuashun.py**：同花顺数据源的具体实现，用于获取板块数据

### 2. 设计模式

- **单例模式**：数据源实例在客户端中保持单例
- **适配器模式**：通过抽象基类适配不同的数据源
- **异步同步转换**：提供统一的接口风格，同时支持同步和异步调用
- **多数据源策略**：不同数据源负责不同类型的数据，Baostock负责股票/指数/基金，同花顺负责板块

### 3. 依赖管理

主要依赖：
- pandas：数据处理和返回格式
- aiohttp：异步网络请求
- requests：同步网络请求
- baostock：Baostock数据源依赖
- lxml：HTML解析（同花顺数据源）
