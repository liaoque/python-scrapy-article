# QuickStock SDK 知识库

## 项目概述

QuickStock SDK 是一个易于使用的金融数据获取工具包，用于获取股票、指数和基金数据。该项目的目标是提供一个既简单又可维护的SDK，解决之前两个版本（`quick_stock` 太简单，`release_config` 太复杂）的问题。

## 目录结构

项目采用了 Python 包的最佳实践 **src-layout** 结构：

```
quickstock/
├── docs/           # 文档目录
├── quickstock.egg-info/  # 包构建信息（自动生成）
├── src/            # 核心源代码目录
│   └── quickstock/ # 主包目录
│       ├── sources/ # 数据源模块
│       │   ├── __init__.py
│       │   ├── baostock.py
│       │   └── base.py
│       ├── __init__.py
│       ├── client.py
│       └── errors.py
├── tests/          # 测试目录
├── MANIFEST.in
├── README.md
├── example.py
├── requirements.txt
└── setup.py
```

## 核心功能

### 数据类型支持
- **股票数据**：基础信息、日线、分钟线、周线、月线
- **指数数据**：基础信息、日线、分钟线
- **基金数据**：基础信息、日线

### API 设计
- **同步接口**：如 `stock_basic()`、`stock_daily()`
- **异步接口**：如 `astock_basic()`、`astock_daily()`
- **统一返回格式**：所有方法都返回 pandas DataFrame

### 数据源
- **固定数据源**：当前仅支持 Baostock
- **数据源接口**：通过抽象基类定义统一的数据源接口

## 技术架构

### 1. 核心模块

#### client.py
- 提供 `QuickStockClient` 类，是用户与SDK交互的主要接口
- 实现了同步和异步两种调用方式
- 内部使用 `_run_async()` 方法将异步方法包装为同步接口

#### errors.py
- 定义了统一的异常处理体系
- 基础异常：`QuickStockError`
- 子类异常：`DataSourceError`、`ValidationError`、`AuthenticationError`、`NetworkError`、`DataNotFoundError`

#### sources/
- **base.py**：定义数据源抽象基类，规定了必须实现的接口方法
- **baostock.py**：Baostock 数据源的具体实现

### 2. 设计模式

- **单例模式**：数据源实例在客户端中保持单例
- **适配器模式**：通过抽象基类适配不同的数据源
- **异步同步转换**：提供统一的接口风格，同时支持同步和异步调用

### 3. 依赖管理

主要依赖：
- pandas：数据处理和返回格式
- aiohttp：异步网络请求
- requests：同步网络请求
- baostock：数据源依赖

**当前问题**：

- 包发现配置缺失：没有指定 `src` 目录，导致无法正确发现包

**解决方案**：
```python
# 更新版本获取路径
def get_version():
    version_file = os.path.join(os.path.dirname(__file__), 'src', 'quickstock', '__init__.py')
    # ...

# 更新包发现配置
setup(
    packages=find_packages(where="src"),
    package_dir={"": "src"},
    # ...
)
```

## 当前问题与解决方案

**问题**：由于 setup.py 配置不正确，导致包无法正确安装和导入。

**解决方案**：修复 setup.py 中的配置，添加 src-layout 支持。

### 2. 功能完整性

**问题**：基金数据功能不完整，缺少分钟线、周线和月线数据。

**解决方案**：在 Baostock 数据源中实现完整的基金数据接口。

**解决方案**：复用事件循环或使用 `asyncio.run()` 改进异步实现。

决定使用 Baostock 作为唯一数据源，简化用户配置，降低复杂度。

### 2. src-layout 结构

采用 Python 包的最佳实践 src-layout 结构，提高代码的可维护性和可移植性。

### 3. 同步异步双接口

提供同步和异步两种调用方式，满足不同用户的需求。

### 4. 统一异常处理

设计了清晰的异常层次结构，提高错误处理的一致性和可理解性。
