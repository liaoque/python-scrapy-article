Installation
============

安装 QuickStock SDK 非常简单，可以通过 pip 工具进行安装。

使用 pip 安装
-------------

推荐使用 pip 安装 QuickStock SDK:

.. code-block:: bash

    pip install quickstock

或者从源码安装:

.. code-block:: bash

    git clone https://github.com/your-repo/quickstock.git
    cd quickstock
    pip install .

依赖
----

QuickStock SDK 需要以下依赖包:

- Python >= 3.7
- aiohttp
- aiosqlite
- pandas
- numpy
- psutil

这些依赖会在使用 pip 安装时自动处理。
